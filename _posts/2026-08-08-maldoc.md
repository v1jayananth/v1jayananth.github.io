## Objective


> Perform detailed static analysis on malicious documents.

Analysts can identify potential threats by analyzing the structure and content of a document and taking steps to mitigate them. This is particularly important today when more businesses rely on digital documents to share and store sensitive information.

If a document is indeed malicious, we have to look for the presence of malicious indicators such as malicious URLs, IP addresses, domains, malicious scripts or code snippets etc.

## Spearphishing attachment

Spearphishing is a common cyber attack targeting specific individuals or organizations through carefully crafted phishing emails, making it seem legitimate enough to open the malicious attachments. 

There are many APTs (Advanced Persistent Threats) and many many malware families, where the initial step, the way they first get their foothold includes phishing emails. 

### Malicious Documents

We often think, "PDFs are 100% safe, because they just display documents", right? Unfortunately, PDF, and a host of other document types, often associated with microsoft office such as DOCX, XLSX, PPTX etc, can have malicious code embedded in them in many different ways. PDF gives the option to embed scripts directly. DOCX, XLSX and PPTX often have malware in the form of macros, that can execute code on a user's system.

## PDF 

PDF or, **Portable Document Format**, consists of a series of objects, organized in a specific structure that instruct it on how to display documents and perform different functionality. 

A PDF often starts with a header like `%PDF-1.7`, that specifies the PDF version

the body of a PDF document looks as follows: 

```
 1 0 obj
<< /Type /Catalog
   /Pages 2 0 R
>>
endobj
2 0 obj
<< /Type /Pages
   /Kids [3 0 R 4 0 R]
   /Count 2
>>
endobj
3 0 obj
<< /Type /Page
   /Parent 2 0 R
   /MediaBox [0 0 612 792]
   /Contents 5 0 R
>>
endobj
4 0 obj
<< /Type /Page
   /Parent 2 0 R
   /MediaBox [0 0 612 792]
   /Contents 6 0 R
>>
endobj
```

This is complemented by a cross reference (xref) table, which acts like a map for the entire document, and at the very end of a PDF document, you will find: 

```
startxref
788
%%EOF
```

which indicate, as which byte, the PDF document starts. In the above code, it could correspond to any of the "<num> 0 obj" lines, and follow the execution path laid out.  


### PDF keywords

- `/JavaScript` or `/JS`: points to javascript that will run when document is opened
- `/OpenAction`: Carry out an action such as running a script
- `/Names`: file names 
- `/URI`: Links to other URLs on the internet
- `/Launch`: Used to run embedded scripts within PDF file itself.

## Analyzing malicious Javascript

Let's say we have javascript code that was extracted from some document. How do we find out what it does? 

1. We can open it in a text editor and read through the code. 
2. Or we can run tools such as `box-js` that **runs the code in a controlled environment** and records the behaviour, reporting IOCs that would be useful to us.

## Microsoft Office Word Document Analysis

Files with `.doc` or `.docx` extension. 

> `.doc` is part of the structure storage format, while `.docx` is a Office Open XML format (OOXML), that is a zipped file containing all data within the document. These documents can be unzipped, by replacing the extension with a `.zip`. 
{: .prompt-info}

What makes these documents malicious are the **Macros**, which are small **Visual Basic (VBA) scripts** that are embedded within the document. Their primary purpose is to automate tasks, but often they are used to execute malicious code. And there's always the other stuff that can make any document malicious, such as embedded objects, links, hidden content etc. 

### Analyzing `.doc` file

1. `oleid` is a good tool, that can extract basic information about the document. 
    - ![oleid]({{ "assets/img/maldoc_5.png" | relative_url}})
2. `olemeta` can help extract property information about the streams. 
3. `oletime` shows creation and modification time of different stream objects present in the document. This way, you can see which parts were modified. 
4. `olemap` displays details about the sectors of the file. 
5. `olevba`: This one extracts **all VBA objects** within the file, and shares summary of the suspicious elements found. 
    - ![olevba]({{ "assets/img/maldoc_6.png" | relative_url}})
    ![olevba]({{ "assets/img/maldoc_6.png" | relative_url}})
6. `oledump.py` can be used to check for embedded macros. 
7. ViperMonkey, or `vmonkey` can be used to emulate the behaviour of malicious macros in office documents.

## OneNote

OneNote is often targeted by APT groups. You can search on MalwareBazaar, for the file_type `one` to find out about this. 

> `trid` is a utility that can identify file types, if `file` fails to find the file type.
